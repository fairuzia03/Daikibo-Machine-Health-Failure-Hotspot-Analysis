# Daikibo-Machine-Health-Failure-Hotspot-Analysis
Tableau dashboard identifying machine failure hotspots across 4 Daikibo factories using May 2021 IoT telemetry. Seiko caused 47% of downtime (480 of 1,030 min), all from LaserWelder machines. Interactive factory filter, KPI cards, Z-pattern layout. Deloitte Australia Data Analytics job simulation (Forage).
